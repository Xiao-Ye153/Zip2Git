ZIP2GIT

Upload zip project lo, langsung ke-push ke GitHub. Gak perlu install git, gak perlu buka terminal. Jalan 100% di browser lo — token GitHub gak pernah dikirim ke server manapun selain langsung ke api.github.com.

Personal Access Token

Belum punya? Buka github.com/settings/tokens/new → centang scope repo → Generate → copy tokennya ke sini.
⚠️ Kalau dicentang, token disimpan di penyimpanan browser HP ini (bukan dikirim ke server manapun) — jangan centang kalau HP-nya dipakai bareng orang lain. Tap "Lupain token" buat hapus kapan aja.
